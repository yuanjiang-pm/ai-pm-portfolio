# AI 产品经理实战课程（K3）

> 面向从互联网软件转型的产品经理。  
> 所有案例均来自 openai/codex 和 openclaw 两个开源项目的真实代码与文档。

## 为什么需要这门课

你过去设计的是"输入 → 规则引擎 → 输出"的确定性管道。  
现在你要设计的是"意图 → 概率系统 → 行为"的不确定性管道。

这门课不教你怎么写代码，而是教你怎么**通过设计约束、脚手架和反馈回路，来管理一个你不完全控制的系统**。

## 课程地图

| 课 | 主题 | 核心问题 |
|-|-|-|
| 01 | 提示词即 PRD | 怎么用自然语言"写需求"？ |
| 02 | 上下文组装 | AI 每轮"看到"什么，由谁决定？ |
| 03 | 工具设计 | 怎么给 AI 设计"手"？ |
| 04 | 权限与安全 | 怎么让 AI 有自主权但不失控？ |
| 05 | 工作流编排 | 多步任务怎么拆解和并行？ |
| 06 | 记忆与状态 | AI 怎么"记住"用户？ |
| 07 | 评估与反馈 | 怎么知道 AI 做得好不好？ |
| 08 | 两种范式对比 | Codex vs OpenClaw 的设计哲学 |
| 09 | 实战案例拆解 | 四个真实案例的完整分析 |
| 10 | 迁移地图 | 你过去的经验怎么映射过来 |

## 学习路径

**第一周**：01 → 02 → 03（建立"提示词-上下文-工具"三角）  
**第二周**：04 → 05 → 06（理解"安全-编排-记忆"三支柱）  
**第三周**：07 → 08 → 09 → 10（评估体系 + 范式对比 + 案例 + 迁移）
