# NCA-GENL备考 D3：PEFT参数高效微调

## 今日主题

在不动"主蛋糕"的情况下，用小手术刀精准调整模型能力 📖

---

## 概念讲解

### 为什么要PEFT？

想象你有一辆调校好的超跑（预训练好的大模型），现在你想让它更适合山路行驶。全量微调就像把整辆车拆了重新组装——贵、慢、还可能改坏原来的好调校。PEFT则是加装一个"山路模式适配器"，不动原车，只加装小部件。

**PEFT的核心思想**：冻结预训练权重，只训练一小部分新增参数。

---

### 四种主流PEFT方法

#### 1. LoRA（Low-Rank Adaptation）⭐ 最常用

**原理**：在每个 Transformer 的权重矩阵旁，平行插入两个小的低秩矩阵 A 和 B。

```text
原始：Y = W × X （冻结）
LoRA：Y = W × X + B × A × X （只训练 A 和 B）

```

**类比**：就像在一本厚书的章节旁贴便签——原书不动，便签上记新笔记。你不需要重写整本书，只需加几张便签就能适应新任务。

**特点**：

- 参数量大幅减少（通常只有原模型的 0.1%\~10%）
- 可以切换不同便签适配不同任务
- 训练稳定，效果接近全量微调

#### 2. Adapter

**原理**：在 Transformer 每层之间插入一个小型的"适配器模块"（通常是两层全连接 + 非线性激活）。

**类比**：像给相机加装滤镜，每个镜头（层）后加一个调色模块，拍照时自动应用滤镜效果。

**特点**：

- 串行插入，需要额外计算
- 不同任务可装不同 Adapter

#### 3. Prompt Tuning / Prefix Tuning

**Prompt Tuning**：不训练模型，也不加 LoRA 矩阵，而是学习一组可调的"软提示"（soft prompts），把这些向量直接拼接在输入 embedding 前。

**Prefix Tuning**：类似，但在每层注意力机制的输入前都加可学习的前缀。

**类比**：就像给 AI 预设一个"开场白"模板，这个模板不是你想出来的，而是模型"学"出来的最优开场白。

#### 4. IA³（Infused Adapter by Inhibiting and Amplifying Activations）

**原理**：用学习到的向量逐元素缩放激活值，比 LoRA 更轻量。

---

### 全量微调 vs PEFT 对比

| 维度 | 全量微调 | PEFT |
|-|-|-|
| 训练参数量 | 100% | 0.1%\~10% |
| GPU 显存 | 巨大 | 显著降低 |
| 存储成本 | 每个任务一个完整模型 | 每个任务只存小模块 |
| 灾难遗忘风险 | 高（可能忘记原能力） | 低（原始权重冻结） |
| 效果 | 通常最好 | 接近全量微调 |

---

## 关键对比

### LoRA vs Adapter

|  | LoRA | Adapter |
|-|-|-|
| 结构 | 矩阵分解（A×B） | 两层全连接 |
| 位置 | 并行于原权重 | 串行插入层间 |
| 计算开销 | 极低 | 中等 |
| 主流程度 | 更流行 | 较少使用 |

### Prompt Tuning vs LoRA

|  | Prompt Tuning | LoRA |
|-|-|-|
| 修改位置 | 输入 embedding | 权重矩阵 |
| 可解释性 | 较差（向量难解读） | 较好 |
| 效果稳定性 | 依赖模型规模（大模型效果更好） | 较稳定 |

## 易错陷阱 ⚠️

1. **❌ LoRA 不是剪枝**

   - 剪枝（Pruning）：删除不重要的权重连接
   - LoRA：添加新的低秩矩阵，原权重保持冻结
   - 考试看到"减少参数量"不要立刻选剪枝，要看上下文
2. **❌ PEFT 不是零成本**

   - 虽然训练成本低，但推理时 LoRA 的矩阵乘法仍然要计算
   - 有些实现会在推理时"合并"LoRA 权重到原始权重来提速，但这需要额外步骤
3. **❌ Prompt Tuning 对小模型效果差**

   - 小模型（<10B）对可学习提示不够敏感，效果不如 LoRA
   - 一般规律：模型越大，Prompt Tuning 越有效

## 练习题

### Q1：LoRA 的核心原理是什么？

A. 删除不重要的神经网络权重B. 在权重矩阵旁并行添加低秩分解矩阵C. 替换原始模型的注意力头D. 为每个 Token 学习独立的嵌入向量

**答案**：B**解析**：LoRA 在冻结的原始权重 W 旁并行添加两个小矩阵 A 和 B，通过 B×A×X 的形式注入新能力。剪枝是 A 选项，C 是模型结构修改，D 是 Embedding 相关方法。

---

### Q2：PEFT 和全量微调的主要区别是什么？

A. PEFT 训练的是整个模型B. PEFT 冻结大部分预训练权重C. PEFT 不能用于生成任务D. PEFT 的效果总是优于全量微调

**答案**：B**解析**：PEFT 的核心就是冻结大部分预训练权重，只训练少量新增参数。A 描述的是全量微调，C 明显错误（PEFT 适用于各种任务），D 太绝对（通常接近但不一定超越）。

---

### Q3：以下哪个场景最适合用 PEFT？

A. 只有一个 GPU 且显存充足，训练 7B 模型B. 需要在多个下游任务上微调，存储资源有限C. 完全从头训练一个新模型D. 对模型效果要求必须达到 SOTA

**答案**：B**解析**：PEFT 的核心优势是"少参数 + 多任务切换"。A 描述矛盾（显存充足还用 PEFT 意义不大），C 是预训练不是微调，D 全量微调更可能达到 SOTA。
